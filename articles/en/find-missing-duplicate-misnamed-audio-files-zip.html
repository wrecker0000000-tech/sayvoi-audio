How to Find Missing, Duplicate and Misnamed Audio Files in a ZIP

Last updated: November 25, 2026

In a voice data project every sentence has a file name, and every name follows a rule. When a project has hundreds of files, a missing take or a typo in a name is easy to miss. This guide shows how to find them fast.

Find the missing files

  1. Open the delivery checker and drop your ZIP.
  2. Paste the list of names you must receive. If you use Project Builder, press Copy expected file names there and paste here.
  3. Press Check. The Missing section lists every name that is not in the ZIP.

Find duplicates

The page finds two kinds. The first is two files with the same name in different folders. The second is the same recording saved under two names, which happens when a take is copied by mistake. It compares the audio itself, so a different name does not hide it.

Find wrong names

  1. Write the pattern, for example {speaker}_{country}_{gender}_{age}_{code}_{speed}_{take}.
  2. Add the allowed values, one line for each part: gender: male,female and age: 18-70.
  3. Every file that does not match is listed with the reason, such as a value that is not allowed.

Good to know

  • A file that matches only when the letters case is ignored is reported as missing, with a note, because many systems treat the two names as different.
  • You can download the file list as a CSV with one column for each part of the name. It is handy as a manifest.
  • Your files stay on your device.
