How to Record a List of Sentences From a Text File, One by One

Last updated: November 6, 2026

Projects that collect speech data usually give you a long list of sentences to read. Recording them from a notes app is slow and easy to get wrong. The Sayvoi voice recorder has a script mode that shows one sentence at a time, with the record button right inside the sentence box.

How it works

  1. Prepare a plain text file with one sentence per line.
  2. Upload it in the recorder. The sentences appear one at a time.
  3. Press record, read the sentence, press stop.
  4. Use Next and Previous to move, or record the same sentence again if you made a mistake.
  5. Open Review to see all sentences and which ones are done.
  6. Download a ZIP in which each file is numbered in order, such as 001.wav, 002.wav.

Tips for a clean session

  • Read the whole sentence once silently first, so you do not stumble.
  • Keep the same distance from the microphone throughout. See how to record clean audio with a phone.
  • Take short breaks. Voice tires and quality drifts after long sessions.
  • Check the noise test again if you move to another room.

Stopping and continuing later

Your script position and takes are saved in the browser, so you can close the tab and continue another day on the same device and browser. Download the ZIP when you finish, because clearing browser data deletes the takes.

Before delivering to a client, run the files through the quality checker and follow the pre-delivery checklist.
