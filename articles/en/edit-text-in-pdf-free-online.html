How to Edit Text in a PDF Online for Free

Last updated: November 19, 2026

You found a typo in a PDF, or a date that must change, and you do not have the original Word file. This tool lets you tap a line, change it and save a new PDF. It runs on your device, so your document is not uploaded.

Change a line of text

  1. Open the tool and choose your PDF.
  2. Stay on Edit text. Move over the page, and each line of text is highlighted.
  3. Tap the line. A box opens with its text.
  4. Write the new text. Change the size, the color or the font style if you need to.
  5. Press Apply, then press Download edited PDF.

If a paragraph has several lines, press Add the line above or Add the line below to edit them together.

Add a new line

  1. Press Add text.
  2. Tap the page where the text should go.
  3. Write the text and press Apply.
  4. Drag the text to move it. Use Smaller and Larger to change its size.

How it works

The tool covers the old text with the color of the page, and writes the new text on top. It does not rebuild the PDF from the inside. That is why it works on almost any PDF, but there are limits.

Good to know

  • The original text may still be hidden under the cover in the file. Do not use it to hide secret information.
  • The new text uses a standard font, so it can look a little different from the original.
  • Text written in Arabic is saved as a picture in that spot.
  • A scanned PDF has no text to tap. Use Erase area and Add text instead.
  • Press Undo if you make a mistake. Always check the saved file.
