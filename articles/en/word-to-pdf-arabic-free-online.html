How to Convert Word to PDF Online for Free, Including Arabic

Last updated: November 19, 2026

You have a Word file and need a PDF to send, print or submit. Many online converters upload your file to a server, and some mix up the order of Arabic text. This tool converts the file on your own device and handles right-to-left text.

Step by step

  1. Open the tool and stay on the Word to PDF tab.
  2. Press Choose a .docx file and pick your document.
  3. Choose the paper size, the margins, the text size and the text direction.
  4. Check the preview. Notes from the file, if any, appear above it.
  5. Press Download PDF, or use the Print option and choose Save as PDF.

Which option to choose

  • Paper size: A4 for most countries, Letter for the United States and Canada.
  • Margins: narrow, normal or wide.
  • Text size: small, normal or large. This changes the whole document.
  • Text direction: leave it on Automatic, so each paragraph follows its own main language. Choose Right to left if an Arabic document looks wrong.

Download or Print?

Download PDF works everywhere, but each page is saved as a picture, so the text cannot be selected. The Print option opens the print window of your browser. Choose Save as PDF there, and you get a smaller file with text you can select and search.

Good to know

  • The tool keeps text, headings, lists, tables and pictures.
  • Headers, footers, text boxes and exact fonts are not kept, so the layout can differ from Word.
  • Old .doc files must be saved as .docx in Word first.
  • Your file is never uploaded. Always check the PDF before you send it.
