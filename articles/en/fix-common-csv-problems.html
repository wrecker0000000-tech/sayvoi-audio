Common CSV Problems and How to Fix Them

Last updated: November 17, 2026

CSV looks simple, but small details break it. These are the problems people meet most often, and how to fix each one.

1. Columns are shifted

A value with a comma inside, such as Alexandria, Egypt, splits into two columns. The fix is to put the value inside double quotes: "Alexandria, Egypt". Good tools do this for you when they export.

2. A quote inside a value

A double quote inside a quoted value is written twice. So He said "hi" becomes "He said ""hi""". If the file has one quote that is never closed, the rest of the file is read as one value.

3. Wrong separator

In some countries, spreadsheets export with a semicolon, because the comma is used for decimals. If all your data appears in one column, the separator is not the comma. Choose the right separator, or use automatic detection.

4. Arabic text looks broken

This is an encoding problem. Save the file as UTF-8. If you open a UTF-8 file in an old program and it shows strange symbols, import it and choose UTF-8 as the encoding.

5. Leading zeros disappear

Numbers such as 007 or a phone number starting with 0 lose their zeros when treated as numbers. Keep them as text. The Sayvoi converter leaves these values as text, so nothing is lost.

6. Rows with a different number of columns

Some rows have fewer or more values than the header. The converter fills the missing values with empty ones, and shows you how many rows were uneven, so you can check them.

7. Two columns with the same name

JSON keys should be unique. The converter renames repeated names, for example name and name_2, and gives empty headers a name such as column_3.
