How to Rename Many Audio Files at Once from a ZIP

Last updated: November 8, 2026

Renaming recordings one by one is slow and easy to get wrong. The Sayvoi batch renamer applies one set of rules to every file at once. It works in your browser, so the files stay on your device.

Step by step

  1. Drop a ZIP file, or select your audio files directly.
  2. Write a name pattern. For example, spk01_{n3} gives spk01_001, spk01_002 and so on. The extension, such as .wav, is kept.
  3. Choose the first number and the order: by name, as listed in the ZIP, or by date.
  4. Optional: find and replace text in the old name, remove spaces and symbols, or change the letter case.
  5. Optional: paste a list of new names, one per line. They are applied in the file order.
  6. Check the preview table, then download the renamed ZIP. You can also download a CSV that lists the old and new names.

Useful patterns

  • {name} keeps the old name. Use it with a prefix, such as ar_{name}.
  • {folder}_{n2} uses the folder name from inside the ZIP.
  • {n4} adds a number padded to four digits, which keeps files in the right order when sorted.

Safety

  • Your original files are never changed. You get a new ZIP.
  • If two files get the same name, the tool adds a number so no file overwrites another.
  • Keep the CSV file. It is your record of which old name became which new name.
