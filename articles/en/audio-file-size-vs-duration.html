Audio File Size vs Duration: How Much Space Does a Minute of Audio Take?

Last updated: November 6, 2026

Before a long recording session you may want to know how much storage you need. For uncompressed WAV the answer is simple arithmetic.

The formula for WAV

Bytes per second = sample rate × bytes per sample × channels. Bit depth 16 means 2 bytes, 24 means 3 bytes.

SettingPer minutePer hour
16 kHz, 16-bit, monoabout 1.9 MBabout 115 MB
44.1 kHz, 16-bit, stereoabout 10.6 MBabout 635 MB
48 kHz, 24-bit, monoabout 8.6 MBabout 518 MB
48 kHz, 24-bit, stereoabout 17.3 MBabout 1.04 GB

MP3 is different

MP3 size depends on the bitrate: roughly bitrate ÷ 8 bytes per second. At 128 kbps that is about 1 MB per minute. See MP3 bitrate explained.

Working backwards

If a file is much bigger or smaller than the table suggests for its length, its real settings may differ from what you expected, for example stereo instead of mono. Use the duration calculator to read lengths, and the quality checker to read the sample rate and channels.

Reducing size

Lower the sample rate or channels only if the project allows it. Otherwise see how to reduce audio file size.
