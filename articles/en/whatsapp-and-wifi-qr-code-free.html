How to Make a WhatsApp QR Code and a Wi-Fi QR Code for Free

Last updated: November 19, 2026

Two of the most useful QR codes are a WhatsApp code, for customers who want to message you, and a Wi-Fi code, so guests do not have to type your password.

A WhatsApp QR code

  1. Open the tool and choose WhatsApp.
  2. Write your number with the country code, digits only. For example 201001234567. Do not add + or 00.
  3. If you want, write a ready message, such as "Hello, I want to ask about your prices".
  4. Download the code and print it on your shop door, card or menu.

When someone scans it, WhatsApp opens a chat with your number and the message already written.

A Wi-Fi QR code

  1. Choose Wi-Fi.
  2. Write the network name exactly as it appears, with the same capital letters.
  3. Write the password and choose the security type. Most home networks use WPA.
  4. Tick Hidden network only if your network name is hidden.
  5. Download the code and put it where guests can see it.

Phones that scan it will offer to join the network, without typing the password.

Good to know

  • Anyone who scans a Wi-Fi code can join your network. Share it only with people you trust, and print it for a guest network if you can.
  • If you change your Wi-Fi password, make a new code. The old one will stop working.
  • The code holds your number or your password inside the picture. Nothing is uploaded to a server.
  • Test both codes with your phone before you print them.
